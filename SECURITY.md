# Security Policy

EarthSCIgen v0.1.0 is a static, browser-only application. It does not require
accounts, API keys, analytics, cookies, a database, or a server-side runtime.

## Supported version

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting

Please open a GitHub issue without including personal data, unpublished
research, credentials, or sensitive geographic information. For a potentially
exploitable vulnerability, use GitHub's private vulnerability reporting when
it is available for this repository.

## Research safety boundary

Generated material is synthetic. It is not peer reviewed, does not represent
observational evidence, and must not be submitted or communicated as genuine
scientific findings.
